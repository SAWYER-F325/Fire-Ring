**修正**
- Codex 的子代理（带着主对话上下文派出去的那种）做完时，Fire Ring 会把整个主对话标成「完成」，其实主任务还在跑。现在只在主对话真正跑完时才显示完成、才响提示音。
- 别的程序在后台用 `codex exec` 调用 Codex 时（比如 Claude Code 让 Codex 生成图片），每一步都会单独冒出一个「Codex 完成了」。现在这类后台调用不再单独显示，状态以发起它的那个对话为准。

**改进**
- 刘海里每条任务的第二行前面加了一个小 logo，一眼就能看出是 Claude、Codex 还是 DeepSeek。

**开源**

**Fixes**
- When a Codex subagent forked with the main conversation's context finished, Fire Ring marked the whole conversation as finished while the main task was still running. It now shows “finished” and plays the sound only when the main conversation is done.
- When another program ran Codex in the background with `codex exec` (for example, Claude Code asking Codex to generate images), each step showed up as its own finished Codex task. These background runs are no longer listed; the conversation that started them shows the status.

**Improvement**
- Each task in the notch now has a small logo before its second line, so you can tell Claude, Codex and DeepSeek apart at a glance.

**Open source**
- Fire Ring is now open source under the MIT License. Issues and pull requests are welcome; see CONTRIBUTING.md in the repository.
