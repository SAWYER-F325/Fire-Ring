**修正**
- Claude Code 的任务在提示框里问过你问题后，如果是由另一个 Claude 会话接着推进、一直跑完的，Fire Ring 会一直显示「等你」。现在只要对话开始了新的一轮，就不再算等你。

**改进**
- 「等你」的任务也能手动清除了：在菜单栏面板或刘海列表里点 ×。清除后，这条对话有新动静之前不会再显示。

已安装旧版本的用户：打开菜单栏面板，底部会出现「有新版本」，点进去下载并安装即可；也可以直接下载下面的 dmg 重新安装。

**Fix**
- A Claude Code task that asked you something and was then carried on to the end by another Claude session kept showing as “Needs you”. It no longer does once a new turn starts.

**Improvement**
- Tasks that need you can now be cleared by hand with the × in the menu-bar panel or the notch list. They stay hidden until that conversation moves again.

On an older version: open the menu-bar panel and click “New version” at the bottom to update, or download the dmg below.
