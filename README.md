<h1 align="center">Fire Ring</h1>

<p align="center">把 AI 编程助手的任务放进 Mac 刘海：哪个在等你、哪个还在跑、哪个已经完成，一眼看清。</p>

<p align="center">支持 Claude Code · Codex · DeepSeek Harness　｜　<a href="README.en.md">English</a></p>

## 三种状态

| 状态 | 标记 | 意思 |
| --- | --- | --- |
| 等你 | 红色火苗 | AI 在问你问题、等你确认方案，或等你批准一个操作 |
| 在跑 | 蓝色火苗（会跳动） | 正在执行，包括后台任务 |
| 完成 | 绿色对勾 | 这一轮已经结束；在原来的 App 里打开它，就会自动清掉 |

## 能做什么

- **刘海提示**：任务完成或需要你时，刘海自动弹出，停留 3、6 或 10 秒；鼠标移上去展开全部任务，点一下直接回到那个对话；「全部清除」会让完成的任务带着火星和火焰声燃烧消失。全屏看视频、写代码时，刘海会自动收起。
- **提示音和通知**：等你或完成时响提示音、发系统通知，声音可以从原创音效和 macOS 自带的里挑；一直没处理会再提醒，也能暂停提醒、按工具开关；Codex 额度或 DeepSeek 余额变低时提醒一次。在设置里点「试一下」就能听到、看到。
- **菜单栏面板**：点菜单栏的三层火图标，按「等你 / 在跑 / 完成」分栏查看，点任意一条跳到对应的 App 和对话。右键点火苗可以暂停提醒、打开设置或退出。
- **额度与余额**：Codex 的 5 小时和每周剩余额度；DeepSeek 的账户余额、今天花了多少和 24 小时余额曲线；Claude 额度用完时提醒几点重置（可选）。显示谁的额度，在设置里逐个决定。
- **用哪个连哪个**：Claude Code、Codex、DeepSeek Harness 各自连接，只用其中一个也可以；没连接的不读取、不显示。
- **深色和浅色**：在设置里选深色（默认）、浅色或跟随系统。刘海本身始终是黑色。
- **开机自动打开**：第一次设置时问你一次：允许、不允许或以后不再提醒。

## 安装

需要 macOS 14 或更新，Apple 芯片（M 系列）。

1. 在 [Releases](../../releases) 下载最新的 `FireRing-版本号-arm64.dmg`。
2. 打开 dmg，把 Fire Ring 拖进「应用程序」。
3. 第一次打开：Fire Ring 还没有苹果开发者签名，macOS 会提示无法验证开发者。打开「系统设置 → 隐私与安全性」，在页面下方点「仍要打开」。只需要一次。
4. 第一次打开会先写出一个手写的 fire 作为欢迎。之后在「连接」里连上你在用的工具，就完成了。

## DeepSeek 余额（可选）

DeepSeek 按量计费，Fire Ring 显示的是账户余额，需要你自己的 API Key：

1. 打开 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys)，用和 DeepSeek Harness 同一个账号登录。
2. 进入「API keys」，创建一个 Key（名字随便填，比如 Fire Ring）。
3. 复制以 `sk-` 开头的 Key，它只显示一次。
4. 在 Fire Ring「设置 → 连接 → DeepSeek 余额」里粘贴并保存。

Key 只存在本机钥匙串里，只用于查询余额（每 10 分钟一次），不会显示，也不会写进日志。

## 隐私与网络

- 任务标题和状态都从各工具在本机留下的记录里读取，只在本机显示，不上传任何对话内容。
- 只有三件事需要联网：查询 DeepSeek 余额（填了 Key 并打开显示才会查）、检查更新、下载更新。
- 网络线路在「设置 → 网络」里自己选：跟随系统代理、指定 HTTP 代理、直连，或者完全断网。
- 每 6 小时检查一次新版本；下载后先校验文件，再替换并重启，设置都会保留。

## 常见问题

**会消耗我的 token 吗？**
不会。Fire Ring 只读取本机记录，不调用任何模型。DeepSeek 余额查询是账户查询，不消耗 token，也不收费。

**为什么看不到 Claude 的额度百分比？**
Claude 桌面版没有在本机留下实时额度数据，Fire Ring 也不会借用你的登录去查询，所以只在额度用完时提醒几点重置，并且默认不显示。

**支持 Intel 芯片的 Mac 吗？**
目前只提供 Apple 芯片版本。

**怎么卸载？**
在设置里退出 Fire Ring，把它从「应用程序」里删掉即可。如果连接过 DeepSeek Harness，建议先在设置里点「断开」，把插件一起移除。
